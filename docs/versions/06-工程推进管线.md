# 语义登记表 · 工程推进管线

> 适用：`daniel-plugins/next/`（分支 `feat/ontology-registry`）
> 铁律：**旧包 `0.9.11/` 与冷备份 `_archive-0.9.11/` 一律不动**；所有改动只发生在 `next/`。

## 3. 依赖关系与顺序

```
P0-1 登记表切片 ──┐
P0-2 追问工具 ────┼─→ P0-3 交付契约＋校验 ─→ P0-4 工序引用 ─→ P0-5 升版打包 ─→ P0-6 验收
                  │        （校验要契约载体）   （引用要契约 id）
```

**不能并行**的原因：P0-3 定义的契约 id 是 P0-4 引用的对象；P0-5 要做版本链同批，必须等前面内容稳定。
