## 二、逐模块需求示例清单

写法与你的 Brand 管理示例一致：**需求描述 → 在 Daniel 里面的操作流程 → Bot 工作流梳理**。

### Brand 管理

#### 综合场景

**需求示例 1：**

需求描述：
"这是我的产品网站地址：https://www.hallidayglobal.com/，你需要读取并且分析后，帮我创建一个Halliday的Brand，你可以参考目前已经创建好的Iphone这个Brand内的信息"

在 Daniel 里面的操作流程：
1. 用户分析网站内容和产品信息（人工）
2. 总结产品基本信息（名称，金额，description）（人工）
3. 总结keywords，竞品（这里可以使用ai suggestion）（人工 + AI）
4. 按照Brand创建流程，输入指定的表单信息（人工）
5. 完成表单创建（人工）

Bot 工作流梳理：
1. 读取需求后进行分析，确认需要调用Daniel中的Brand功能模块和对应接口（Bot自动化）
2. 开始分析产品网站地址，匹配Brand创建表单需要的字段输入（Bot自动化）
3. 阶段性暂停，输出完整表单创建信息用户确认（目的在于跟用户确认是否需要补充，调整）（人做判断 + Bot自动化）
4. 确认后开始创建（Bot自动化）
5. 任务完成，输出结果说明（同时提及是否需要把Category Setting也完成配置）（人做判断 + Bot自动化）

**需求示例 2：**

需求描述：
"Halliday这个Brand我已经建好了，你参考同品类竞品的配置，帮我把竞品和industry keywords补齐，然后顺手把Category Setting也配好"

在 Daniel 里面的操作流程：
1. 打开Brand详情页，翻看竞品和关键词字段，对比同品类其他品牌的写法（人工）
2. 把竞品的官网信息复制到Brand配置里（人工）
3. 切到Category Setting页，选择品类、逐个添加竞品和正负向关键词（人工）
4. 保存并回看配置是否生效（人工）

Bot 工作流梳理：
1. 读取Brand现有配置，与同品类品牌对比，输出建议补齐的竞品与关键词清单（Bot自动化）
2. 阶段性暂停，输出清单等用户确认（竞品口径会直接影响后续声量统计的分母）（人做判断 + Bot自动化）
3. 确认后更新Brand配置，并完成Category Setting（品类、竞品、正负向关键词）（Bot自动化）
4. 回读配置，与改动前逐项对照，输出"改了什么"的说明（Bot自动化）
5. 任务完成（人做判断 + Bot自动化）

**需求示例 3：**

需求描述：
"我这里有三个产品站，分别是……，帮我分别建好Brand，每个都配好品类和关键词，建完给我一份清单"

在 Daniel 里面的操作流程：
1. 逐个打开产品站，整理三份表单信息（人工）
2. 依次在Brand页创建三个Brand（人工）
3. 逐个进入Category Setting完成品类配置（人工）
4. 手工整理一份清单，记录每个Brand的名字和ID（人工）

Bot 工作流梳理：
1. 依次分析三个产品站，输出三份表单信息供确认（Bot自动化）
2. 阶段性暂停，确认三个Brand分别归属的工作区（Brand按工作区隔离，写入必须显式指定，否则会落到当前活跃的那个工作区）（人做判断 + Bot自动化）
3. 确认后批量创建Brand，并逐个完成品类配置（Bot自动化）
4. 逐个回读，核对所属工作区与配置项（Bot自动化）
5. 输出清单：Brand名称、ID、所属工作区、品类与竞品（Bot自动化）

### AI红人搜索

#### 综合场景

**需求示例 1：**

需求描述：
"切换到Halliday这个Brand下，我想找一批频道受众以男性为主，年龄在25 - 34，均播和互动率不错且视频风格跟产品使用场景比较匹配的专业测评类的红人，然后新建一个Hallidat First Pitch的List，合适的红人保存到这个list中"

在 Daniel 里面的操作流程：
1. 分析产品Brief以及说明文档，整理出一份Halliday相关的品牌信息后创建一个Brand（竞品，keywords，Description，参考价格和Marketing目标国家）
2. 完成Category Setting（根据Halliday提炼出对应的cateory标签，竞品）
3. 分析产品Brief以及说明文档梳理出一份搜索词清单（这一步非常关键，搜索词清单的覆盖面以及质量会直接决定最终搜索结果的质量）
4. 根据搜索清单里面的tag，长句，短尾词或者tag组合词，依次在Brand Deep或者AI open进行搜索执行
5. 每次搜索结果需要配合系统内的Filter功能进行人工筛选（这一步最耗时，因为需要执行多次搜索+查看kol对应的详细信息后进行人工判断）
6. 对于合适的KOL点击save保存到创建好的目标List中
7. 分享List，任务完成

Bot 工作流梳理：
1. 直接给Bot下达指令：
   "我有关于Halliday的产品Brief以及一些相关的产品说明文档，帮我先创建一个Brand后完成相关的配置以及创建一个Halliday Pitch KOL的红人list。然后我想找一批频道受众以男性为主，年龄在25 - 34，均播和互动率不错且视频风格跟产品使用场景比较匹配的专业测评类的红人，适合的KOL帮我添加到list中。"
2. Bot开始根据需求对Daniel进行调度，自动化工作流如下：
   （1）信息分析，自动创建Brand，Cateory Setting配置以及Halliday Pitch KOL的空白list（有信息缺失或者不确定信息暂停询问）
   （2）创建完成，阶段性暂停等待用户确认后流转（同时可以直接在Daniel里面进行确认，用户需要的只是下判断和给结论）
   （3）开始执行搜索词清单输出（垂类，扩圈两大方向+三种输入类型）
   （4）阶段性暂停，输出清单等待用户确认（补充或者选取部分或者全量推进到下一步）
   （5）开始调度Daniel的Deep Search和AI Open进行组合搜索（单次执行并发搜索）
   （6）单次搜索结果分为两步筛选（根据KOL的卡片信息进行一轮初筛，再对剩余KOL进行一轮详细信息填充后进行一轮精筛），符合要求的自动推送到创建好的list中
   （7）分批次搜索结果返回后暂停待用户确认继续搜索或者结束搜索
   （8）用户确认结束后，输出剩余待执行的搜索词清单
   （9）任务完成

**需求示例 2：**

需求描述：
"这批红人是我从别处收来的名单，你按我们的准入标准筛一遍，合适的进第十批的list，不合适的给我原因分布"

在 Daniel 里面的操作流程：
1. 逐个打开红人频道详情页，核对粉丝量、国家、最近更新（人工）
2. 打开受众分析，核对受众国家与性别年龄（人工）

Bot 工作流梳理：
1. 读取名单，批量调用频道详情与受众接口完成富化（Bot自动化）
2. 按准入标准判定：粉丝量级、受众地域、内容匹配度、播放与互动质量（Bot自动化）
3. 合适的批量写入目标list（Bot自动化；批量写入时系统的评分与优先级会按当前规则重算，所以要同时输出我们判的档和系统重算的档）
4. 不合适的按原因归类，输出通过／不通过分布（Bot自动化）
5. 阶段性暂停，输出分布与名单供用户确认（人做判断 + Bot自动化）
6. 任务完成

### Saved Lists

"把Halliday第一批和第二批的list合并，去掉已经在follow up的那部分，建一个新list"

3. 新建一个list，把剩下的人逐个save进去（人工）

4. 确认后批量写入新list（Bot自动化）
5. 回读新list，核对人数与成员（Bot自动化）

**需求示例 2：**
