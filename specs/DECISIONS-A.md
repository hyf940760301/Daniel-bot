## D-064 · 登录后"窗口消失"的根因：Electron 默认"最后一个窗口关闭即退出"

| 项 | 内容 |
|---|---|
| 日期 | 2026-11-02 |
| 现象 | 登录成功、session 已写（0600），但主窗口从不出现，进程直接退出 |
| 根因 | `main()` 里 `window-all-closed` 处理器注册在**登录闸门之后**；登录窗关闭的那一刻**还没有监听器** ⇒ 触发 Electron 默认退出行为（`app.quit()` 来自 Electron 内部） |
| 修复 | 在 `main()` **之前**注册一个空的 `window-all-closed` 守卫；登录窗关闭不再导致退出 |
| 附带修复 | 主窗口 show 后显式抢前台（`window.focus()` + `moveToTop` + macOS `app.focus({steal:true})`），解决"窗口在但被系统判为 hidden" |
| 验证 | 真机：登录窗 → 输对 → **主界面自动出现**；重启跳过登录；session `drwx------`/`-rw-------`；密码错显示服务端原文 |
| 教训 | 任何"启动早期就开窗"的流程，都必须先注册 `window-all-closed`，否则中间态会被当成退出信号 |
