# daniel bot app（规划中）

## 定位

基于 **DSH 基座** 的 macOS 可安装应用，把 Daniel Bot 的能力包成"别人装完就能用"的形态（D-005 / D-008）。

## 一期目标

一个**可以给到别人、在自己电脑上安装即用**的程序包；不含 App Store 分发、不含账号体系。

## 当前状态

方案在 `specs/S2-方案设计.md`（Electron ≥35 + 随包 Python + 钥匙串存密钥 + 未签名 ad-hoc 分发）。
**尚未开始构建**；S4 风险表与三个 spike（Electron 真启动、Keychain ACL、冷跑门禁）未做。

## 构建前必须先解决

1. Electron ≥35（内置 Node 22，否则工具执行即崩）；
2. 凭据适配器（禁用 DSH 自带明文凭据库）；
3. 包内容白名单（客户材料不进包，除用户已书面接受的客户名）。
